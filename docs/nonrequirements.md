| クラウドプロバイダー | Microsoft Azure |

| カスタムドメイン | 不要（Static Web Apps 標準の既定ドメインで運用する） |

## 2. 開発技術

| 項目 | 内容 |
|---|---|

## 3. 非機能要件（デモアプリケーション前提）

本アプリケーションはデモ用途であるため、以下の非機能要件は最小限とする。

| 項目 | 内容 |
|---|---|
| 認証・アクセス制御 | 不要（誰でもアクセス可能な公開アプリケーションとする） |
| ロギング・監視 | 不要（Application Insights 等の監視基盤は導入しない） |
| 可用性・パフォーマンス目標 | 特筆すべき数値目標は設けず、Azure Static Web Apps 標準プランの提供水準に準拠する |
| セキュリティ | Azure Static Web Apps の標準機能（HTTPS 提供等）に準拠する |
| 対応ブラウザ・デバイス | 特筆すべき制約は設けず、モダンブラウザでの動作を前提とする |
| 多言語対応 | 不要 |
