# 機能要件（Functional Requirements）

## 1. 概要
四則演算（加算・減算・乗算・除算）ができる、電卓インターフェースのWebアプリケーションを提供する。

## 2. 入力機能

| 項目 | 内容 |
|---|---|
| 数字キー | 0〜9 の入力に対応する |
| 小数点キー | 小数点（.）の入力に対応する |
| 演算子キー | 加算（+）、減算（-）、乗算（×）、除算（÷）に対応する |
| イコールキー | `=` 押下で計算を実行し、結果を表示する |
| 符号反転キー | 表示中の数値の正負を反転する（+/-） |
| パーセントキー | パーセント（%）計算に対応する |
| メモリキー | M+（メモリ加算）、M-（メモリ減算）、MR（メモリ呼び出し）、MC（メモリクリア）の4つに対応する |
| AC（All Clear）キー | 入力中の値・計算状態をすべてクリアする |
| Delete（バックスペース）キー | 現在入力中の数値の最後の1桁を削除する |
| キーボード操作 | 画面上のボタン操作に加え、物理キーボードからの入力にも対応する |

## 3. 計算仕様

### 3.1 四則演算
- 加算、減算、乗算、除算の基本演算を行う。

### 3.2 パーセント（%）計算
- 経歴的（前の値に対する割合）な計算方式とする。
  - 例: `100 + 10%` → `110`（前の値100に対して10%分を加算）

### 3.3 メモリ機能
- M+：現在の表示値をメモリに加算する。
- M-：現在の表示値をメモリから減算する。
- MR：メモリに保存されている値を呼び出し、表示する。
- MC：メモリの内容をクリアする。

### 3.4 演算子の連続入力
- 演算子を連続で入力した場合、直前に入力された演算子を新しい演算子で上書きする。

### 3.5 ゼロ除算
- 0による除算が発生した場合、ディスプレイに `0 DIV` と表示する。

### 3.6 計算履歴
- 計算履歴の保持・表示機能は設けない（都度の入力・結果のみを扱う）。

## 4. ディスプレイ仕様

| 項目 | 内容 |
|---|---|
| 表示桁数 | 最大8桁とする |
| 桁あふれ時の扱い | 計算結果が8桁を超える場合は、四捨五入して8桁に収める |
| 小数点表示 | 小数点はディスプレイ上で表現できる範囲で表示する |
